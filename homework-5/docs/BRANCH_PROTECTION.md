# Branch Protection — main

Рекомендуемые настройки GitHub/GitLab:
1. Изменения в `main` только через Pull Request / Merge Request.
2. Требовать 2 одобрения; автор не может одобрить собственный PR.
3. Требовать актуальность ветки PR относительно `main`.
4. Обязательные CI-проверки: `dotnet restore`, `dotnet build -c Release`, `dotnet test -c Release`, проверка SQL-миграций.
5. Запретить force-push и удаление `main`.
6. Все обсуждения ревью должны быть разрешены до merge.
7. Production-секреты хранить только в CI/CD Secrets или Variables.
8. Релизный тег `v1.9.0` подтверждает ответственный за релиз.

Для учебной работы, если второго проверяющего нет, можно указать одно одобрение; для рабочей команды предпочтительно два.
